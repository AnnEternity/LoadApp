# Download Manager App

Download Manager App is an educational Android project developed as part of a Udacity course.
The project focuses on building a custom download experience with rich animations and user feedback.

The application allows users to download a file from the Internet by interacting with a custom animated button.
During the download process, the UI visually reflects different states through animations and progress indicators.

### Features

* Custom download button with animated width expansion
* Dynamic button text updates based on download state
* Circular progress animation (0°–360°)
* File download from the Internet
* System notification triggered upon download completion
* Navigation to a detail screen when the notification is tapped
* Automatic dismissal of the notification after interaction
* Download status displayed and animated using MotionLayout on the detail screen

### Purpose

This project was created as a practice assignment to explore:
* Android animations
* Custom view interactions
* Notifications and deep linking
* MotionLayout for UI transitions
* Handling download states and user feedback
* Technologies
* Kotlin
* Android SDK
* MotionLayout
* Notifications API
* Custom Views and Animations

### Notes

This application is intended for educational purposes only and was built to demonstrate animation and UI interaction concepts taught in the course.
